Tentang Disney API

Website ini terhubung langsung dengan Disney API (disneyapi.dev), sebuah layanan antarmuka pemrograman aplikasi publik yang menyediakan data lengkap mengenai karakter, film, dan serial klasik maupun modern dari dunia Disney.

Karakter Disney

Website interaktif ini dibangun untuk menampilkan data karakter klasik dan modern dari Disney API. Bertujuan untuk memberikan informasi visual yang menarik, lengkap dengan daftar film tempat karakter tersebut muncul.
